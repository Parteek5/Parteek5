## 🚀 Featured Projects

<details>
<summary><b>🧠 Vector.db — A Vector Database Built From Scratch in Python</b></summary>
<br/>

A fully working vector database implemented in pure Python (standard library only), with a browser-based UI. Implements **HNSW**, **KD-Tree**, and **Brute Force** search side-by-side, plus a complete **RAG pipeline** powered by a local LLM via Ollama — built to show how production vector databases like Pinecone, Weaviate, and Chroma actually work under the hood.

| Attribute | Detail |
|---|---|
| **Stack** | Python (stdlib only), Ollama (nomic-embed-text, llama3.2), HTML/JS frontend |
| **Scale** | 3 search algorithms, 3 distance metrics, real-time 768D document embeddings |
| **Performance** | HNSW achieves O(log N) search vs O(N) brute force; live algorithm benchmarking built in |
| **Security** | Fully local inference — no data leaves the machine |
| **Impact** | Educational deep-dive project demystifying how modern vector search engines work |
| **Repository** | [github.com/Parteek5/Vector.db](https://github.com/Parteek5/Vector.db) |

The core is a hand-rolled HNSW implementation (multilayer navigable small-world graph) alongside a KD-Tree and brute-force baseline, with a full REST API for insert/search/delete/benchmark. A document tab embeds real text via Ollama's `nomic-embed-text` model, chunks it, indexes it in HNSW, and a RAG tab lets you ask questions answered by `llama3.2` grounded only in your own inserted documents — with a live 2D PCA scatter plot showing the embedding space and semantic clusters forming in real time.

</details>

<details>
<summary><b>😴 Drowsiness Detection System — Real-Time Driver Safety with Computer Vision</b></summary>
<br/>

A real-time computer vision safety system that monitors a driver's eyes through a webcam feed and triggers an audio alert the moment signs of drowsiness are detected — built to demonstrate how classical CV techniques can solve a genuinely safety-critical problem without deep learning overhead.

| Attribute | Detail |
|---|---|
| **Stack** | Python, OpenCV, dlib (68-point facial landmark predictor), imutils, playsound |
| **Scale** | Real-time frame-by-frame video processing from a live webcam feed |
| **Performance** | Low-latency per-frame landmark detection suitable for continuous monitoring |
| **Security** | Fully offline — all processing happens locally, no video data is transmitted |
| **Impact** | Practical safety application: detects drowsy/closed-eye states and sounds an alarm before a driver falls asleep |
| **Repository** | [github.com/Parteek5/Drowsiness_Detection_system](https://github.com/Parteek5/Drowsiness_Detection_system) |

Uses dlib's pretrained 68-point facial landmark model to locate the eyes in each frame, then computes the **eye aspect ratio (EAR)** — a classic geometric signal that drops sharply when eyes close. When the EAR stays below a threshold for a sustained number of frames, the system triggers an audio alarm (`music.wav`) to wake the driver, all running in real time on a standard webcam.

</details>

Built as a low-level networking project to complement ML systems work — understanding how data actually moves at the packet level informs better intuition when building real-time systems (like the drowsiness detector) that depend on efficient, low-latency data flow.

<details>
<summary><b>⚙️ One-time setup: enable the snake animation</b></summary>
<br/>

The snake above is generated automatically by a GitHub Action. To activate it in this repo:

1. Create a new file at `.github/workflows/snake.yml` in this repository.
2. Paste in the workflow below and commit it to `main`.
3. Go to the **Actions** tab → select **Generate Snake** → click **Run workflow** to trigger it the first time (it also re-runs automatically every 6 hours).
4. The action pushes generated SVGs to an auto-created `output` branch — no manual branch setup needed.
5. Once the run finishes, the image above will render your real contribution graph as an animated snake.

```yaml
name: Generate Snake

on:
  schedule:
    - cron: "0 */6 * * *"
  workflow_dispatch:
  push:
    branches:
      - main

permissions:
  contents: write

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - name: Generate snake animation
        uses: Platane/snk@v3
        with:
          github_user_name: Parteek5
          outputs: |
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark
            dist/github-contribution-grid-snake.svg

      - name: Push snake to output branch
        uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

> Note: the snake only shows squares if your GitHub account has real commit activity to display — a fresh or empty contribution graph renders an empty track.
